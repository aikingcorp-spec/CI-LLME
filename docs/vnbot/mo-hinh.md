# Nối mô hình

Mở menu tài khoản cuối thanh bên, chọn Cài đặt rồi Mô hình.

Chọn cách kết nối mà màn hình cung cấp: đăng nhập tài khoản hoặc nhập khóa API qua ô bảo mật. Kiểm tra kết nối rồi chọn mô hình muốn dùng.

Sau khi lưu, gửi một tin nhắn thử. Nếu kết nối hết thời gian chờ, kiểm tra địa chỉ dịch vụ và mạng trước khi thay khóa; hết thời gian chờ không nhất thiết là khóa sai.
