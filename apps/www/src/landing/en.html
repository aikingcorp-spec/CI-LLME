Features

Hand off work like you would to a colleague. Your bots remember, work on their own, and report back to you.

One job per bot

FAQ

Frequently asked questions

Is VNBot free?

Yes. All current features are free. You only pay for your own AI plan, directly with your provider.

Why does Windows warn me about the installer?

VNBot is new and this preview is unsigned, so Microsoft SmartScreen does not yet recognize the file. A warning does not mean the file contains a virus. Click “More info”, then “Run anyway”. Future releases will be signed.

Should I download the .exe or the .msi?

Most people should use the .exe. The .msi is for work computers or installs through admin tools; it may also show a UAC permission prompt.

How can I verify the download?

Open PowerShell in your Downloads folder, run

Get-FileHash .\VNBot-Setup-0.3.7-x64.exe -Algorithm SHA256

and compare the result with the SHA-256 on this page. If they differ, do not run the file. Delete it and download it again.

Is there a version for Mac, iOS, or Android?

Coming soon. VNBot currently has an installer for Windows 10/11 64-bit, a Linux AppImage or .deb for x86_64, and a web app at app.vnbot.run.

How does the web app differ from the desktop app?

The desktop app turns your computer into a node, where bots run and keep their data. The web app at app.vnbot.run connects to your node so you can assign tasks and see your bots at work.

Where is my data stored?

Chats and data stay on your computer, not on VNBot’s servers. API keys and connection credentials are encrypted.
